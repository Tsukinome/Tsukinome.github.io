Behind the page

How this portfolio stays current

No build step, no framework, no backend. One HTML file, one stylesheet, two small scripts, hosted free on GitHub Pages.

Curate in one config

Project titles, summaries, highlights and tags live in a single JavaScript object. Adding a project is adding one entry.

Fetch live data

On load the page calls the public GitHub REST API for the profile, each repository, its language breakdown and its README. No token needed.

Cache and degrade gracefully

Responses are cached in the browser for an hour to respect the 60 requests per hour limit. Private repos and rate limits show a clear notice instead of a broken card.

Render, don't rebuild

Markdown READMEs are rendered and sanitised client-side, so updating a project on GitHub updates the portfolio too.

const api = "https://api.github.com/repos/" + user + "/" + repo;
const [meta, langs] = await Promise.all([
  cachedFetch(api),                 // stars, forks, pushed_at, description
  cachedFetch(api + "/languages"), // { "Jupyter Notebook": 5760053, ... }
]);
renderCard(project, meta, langs);   // curated text + live numbers
